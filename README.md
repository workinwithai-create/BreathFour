# BreathFour

Four-bar live breath desk for bedroom producers and AI-music finishers.

Chorus one runs into verse two with no air. BreathFour writes four live-instrument bars between the last chorus pocket and the next verse downbeat, then verse two enters smaller.

Live chairs only: FluidR3 piano, nylon, upright, kit, trumpet, violin (samples hosted with PreEight).

Distinct from TagFour, ModEight, LiftTwo, PreEight, AfterHook, EndEight, LastHook, ThinFour (same-loop thin), FadeEight (ending fade), DieTwice (false ending), HoldFour (section hold).

## Form

1–4 chorus pocket · 5–8 breath · 9–12 verse re-entry

## Play

- A · Chorus loop
- B · Full form
- 8 · Breath + verse only
